---

## 🎯 Die Kern-Idee

Das Spiel verzichtet bewusst auf ein starres, 30-seitiges Paragraphen-Regelwerk. Stattdessen gibt es Kindern und Spielern ehrliche, naturwissenschaftlich fundierte Werkzeuge an die Hand:

1. **Die Arena (Das Spielfeld):**  
   Ein vertikaler Schnitt durch einen echten historischen Ort (Prototyp: *Kirchenmauer Lieberose*, Brandenburg) mit 10 Mikro-Nischen entlang eines extremen Höhen- und Sonnengradienten (Z-Achse: heiße Mauerkrone oben vs. kühler, feuchter Sockel unten).
2. **Das Fugen-Netzwerk (Doppelseitige Streifen):**  
   Physische Spielsteine (Wurzel, Pilzmyzel, Ameisenstraße), die direkt in die Mörtelfugen zwischen den Ziegeln gelegt werden. Wächst eine Verbindung, wird der Streifen einfach auf die Rückseite umgedreht (*Level 1 ➔ Level 2*).
3. **Die Ammen-Plättchen (Moos-Patches):**  
   Grüne Filz-/Karton-Inseln, die direkt auf die Steinflächen gelegt werden und lebensfeindliche Ziegel in feuchte Keimstätten verwandeln.
4. **Die Pflanzen-Karten (Level 1 & Level 2):**  
   8 charakterstarke urbane Pionierpflanzen mit echten botanischen Zeigerwerten auf einer intuitiven Skala von **1 bis 3** (Licht, Wasser, Wurzelraum, Triebe).

```
        ☀️ LICHT          💧 WASSER          🪴 WURZEL / TIEFE
   1 = Schatten       1 = Trocken        1 = Flacher Spielraum (Mörtelspalt)
   2 = Wechsellicht   2 = Mäßig feucht   2 = Normaler Mauerhohlraum
   3 = Volle Sonne    3 = Feucht/nass    3 = Tiefe Trümmerkluft
```
